# Admission and failed-exit boundary — proposed contract, no operation selected

These are requirements for a future separately reviewed controller/collector,
not executable steps, a native recipe or permission to call C1. The clock packet
does not implement the missing collector, touch actual HOLDs or assert readiness.

## Entry, effect and post-effect are one nonrenewable interval

1. Original epoch binds full genuine source/PID-start/peer/adapter/raw/capture/
   catch and host clock boot/namespace, plus target runtime identity separately.
   Exact profile/client/image/source pins and all still-required phase costs are
   fixed before effects; no collector record replaces authentic evidence.
2. Before each admitted operation, validate acquired read-only historical HOLD
   descriptions/metadata/bytes/path, roots and source pins under existing C1
   serialization, plus complete original/prior clock/counter/catch constraints.
   Genuine raw intervals, native expiries, immutable earlier-only global/phase
   caps, continuity and reserves are separate mandatory gates. No raw/source/
   catch/coverage association is established by a frozen dataclass or receipt hash.
3. Record one exclusive intent while private ledger is safe, then consume its
   elapsed time. Any check/ledger cost between observation and effect is included;
   old evidence does not become "now". A discontinuity in that gap cannot be
   handled by simply taking a newer sample and declaring a clean epoch.
4. One serialized parent effect loop only, with its own selected conditional RX/
   deadline checks. No concurrent external clock/status/UART poller, helper edits
   or source changes during active lease. Such loop checks are not zero-gap
   continuity proof. No effect is admitted while that proof is missing here.
5. Normal AND admitted exceptional returns require independent available-owner
   read-only root/HOLD/source postchecks, and future actual timing/native expiry/
   epoch/catch/RXTX/output checks with the **original** global/phase caps. Failures
   are not repaired by resampling, a later equal triple or renewed coverage.
   Postchecks cannot retroactively establish entry admission or prevent an already
   occurred effect. Completion is not valid until all required evidence is normal.

## Required refusal matrix (symbolic branches, not executed cases)

| Condition | Consequence; never a fallback |
|---|---|
| Malformed types, bool-as-int, bounds overflow, missing clock ID/value, reordered/duplicate slot/sequence, l>u, noncanonical schema | Reject before effect; no parsing/normalization into a plausible sample. |
| Unsupported clock/API, failed/partial read, refused sample, missing reviewed enclosure, age/width bound unset or exceeded | UNKNOWN/refusal. No interpolation, retry-until-equal, rounding into agreement, dropped slow record or alternate clock. |
| Original/current/previous host boot/domain/source/PID-start/peer/raw/adapter association missing or changed | Epoch/source failure; preserve unexplained owner, no restart/reopen/rebind/status baseline adoption. |
| Previous sample/cap only valid against previous, not original | Refuse, preserving R1. No sliding window erasing original contradictions or original earlier deadline. |
| B/M change proves suspend or contradicts documented model | Sticky clock failure. No reanchor, remove interval or continue on residual budget. |
| B/M intervals overlap but allow nonzero suspend, or sampling gaps not covered | UNKNOWN_SUSPEND is refusal under current policy. No consistency-as-PASS or tolerance grant. |
| W/M change proves model inconsistency, observed clock step/backward value or lost jump evidence | Clock failure/unknown as appropriate; neither later corrected UTC nor extra budget heals it. Known rate slew is not automatically a discrete step, but needs reviewed semantics, not an arbitrary tolerance. |
| Endpoint wall values look continuous but intervening steps cannot be excluded | Unknown continuity, refuse. Compensating steps or sub-interval jumps are not disproved by equal/overlapping endpoints. |
| Negative/zero remaining, expired native B/M/arm limit, insufficient150s+cost, unknown phase cost, stale boundary | Budget refusal; no renewal or throughput guess. A positive minimum alone cannot resolve unknown suspend. |
| Catch consumed/unarmed/missing lineage or incomplete raw RX/TX/quiet evidence | Catch/epoch failure even with ample time. No ACK/flag/dataclass equivalence to live catch. No password/key/recovery retry. |
| Original read-only HOLD/source/root check fails, unavailable or unpinned | Refuse/failed exit; no raw-baseline pin during reconciliation, marker repair, lock reacquisition or original write. |
| Effect or postcheck fails/times out/has unknown delivery | New attempt stays IN_FLIGHT_UNKNOWN/HOLD or failed; no effect retry/rescue or retrospective success. Both historical failures remain independent. |
| Ledger write is short, raises, or fsync uncertain | One-shot poison, no append/diagnostic/write/fsync retry. Attempt independent already-owned read-only checks even if ledger is corrupt/closed. Keep first failure separate from secondary check outcomes. |
| Close/cleanup is uncertain | Clear owned host slot then one close only, no numeric-FD retry, target retention or actual DMA retirement claim. Failure and permanent HOLD remain authoritative. |

Public errors/results must be fixed safe classifications/codes, not raw samples,
absolute host times, private paths/digests/UUIDs/credentials or traceback locals.
Authentic collected raw records/owner/provenance remain private outside Git under
existing limits. Source/profile hashes and public equations alone never prove
that an authentic collector ran or that current operation admission exists.

## What remains untouched

C1v2 API/equal-clock guards, R1 original+previous and R2 failed-exit owner checks,
strict historical read-only role/private-output separation, permanent new marker,
unknown-write poison, no retry and all bounded evidence/memory limits remain.
The original radio/reset HOLDs are not read, changed, cleared, reclassified or
retried. Historical catch is consumed; no current operator/manual-OFF handoff is
available by inference. Missing staging watchdog/recovery/finite phase-cost and
actual collector prerequisites remain independent. Parent alone hardware; no
operator request, clocksampler, capture, controller, query, boot or reset follows.
