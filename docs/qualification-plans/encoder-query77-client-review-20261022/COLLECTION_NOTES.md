# Static collection limits

Only this fresh review directory is writable. Standalone reviewer Python performs
public read/hash/receipt/ELF/ar inspection with no subprocesses or candidate/author
script imports/main execution. No compiler, generator, test, guard, listener,
client/default/help, program or ELF is run. No current target/device/proc/sysfs,
UART/RPC/status/network/private IO; no active composition-lane inspection.

All original source/build/receipts remain immutable. Loader paths are aliases and
final-observed metadata, not unique binaries or an all-pre-use closure. Collection
UTCs do not establish hardware/owner/expiry facts. Any collection error is retained
in its exclusively new STATIC receipt, not treated as a candidate/runtime failure.
No collection error or policy rejection occurred before initial collection.
