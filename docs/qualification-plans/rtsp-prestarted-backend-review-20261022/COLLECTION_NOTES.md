# Static collection notes

Independent review uses only public reads, hashes, receipts, source deltas and
archive/ELF metadata. No candidate or author script is imported/executed; no
compiler/toolchain/test/generator/guard/listener/program/target operation occurs.
Reviewer Python is standalone evidence collection only, with no subprocesses.

Old retention91-input/five-output preservation is hash-only, as requested; those
siblings are not semantically inspected, adopted or composed. Central plans,
AGENTS, Git/index and frozen listener source/review are not accessed by this
collection. No current native state or timing-expiry inference is made.

No read-tool collection error or policy rejection occurred before the first
collection. Any collection error is retained in its fresh STATIC JSON receipt;
it must not be represented as a candidate runtime failure. The author's initial
static-finalizer bookkeeping error is separately retained in author evidence and
is not an independent-review error, compiler failure or policy rejection.
